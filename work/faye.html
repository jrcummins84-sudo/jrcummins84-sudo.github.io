Independent product project

Faye

A personal AI operating system exploring how context, memory, reasoning and controlled action can reduce administrative work.

Role: Product strategy / design / AI-assisted developmentStatus: Evolving personal project

The product premise

Faye began with a practical question: what if an AI assistant managed more of the system around a decision instead of waiting for another prompt?

The project treats AI as a personal operating layer for memory, planning, decision support, monitoring and action. The goal is not “more chat.” It is less administrative work.

A system, not a chatbot

Faye is designed around five connected layers: context → memory → reasoning → actions → interface. That model makes state, evidence and boundaries part of the product design rather than hidden implementation details.

Keep complexity in the system. Keep the interface clear.Primary surfaces should show what matters now, what changed and what decision remains.

Design principles

The project emphasizes state freshness, context isolation, source confidence, reversible automation and learning from correction. These principles came from repeated logic and UX audits as the app evolved.

Faye is also Josh’s first major software-building project. It has become a practical laboratory for product architecture, Android development, AI-assisted coding, QA and systems thinking.

What this demonstrates

Product strategy · AI systems thinking · UX / information architecture · engineering collaboration · QA · continuous learning.

The through-line is the same one visible in Josh’s learning-technology work: understand the complicated system, model it clearly, then make it easier to use.
